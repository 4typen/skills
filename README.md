# Agent Skills

Reusable skills for AI coding agents (Pi, GitHub Copilot, and other agents that support the [Agent Skills](https://agentskills.io/) format).

## Install

```bash
npx skills add 4typen/skills -g
```

The CLI lists the skills and lets you pick them. `-g` installs them for all projects.

## Update

```bash
npx skills update -g
```
